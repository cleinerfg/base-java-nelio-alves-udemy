# Java & Orientação a Objetos

Repositório com exercícios e projetos desenvolvidos no curso do professor Nélio Alves (Udemy), cobrindo do básico ao
avançado em Java.

---

## Conceitos Abordados

- **Fundamentos:** Entrada/saída, manipulação de `String`, `Math`, `Bitwise` e API de datas (`LocalDate`,
  `LocalDateTime`, `Instant`).
- **POO:** Classes, herança, polimorfismo, abstração, enums e exceções personalizadas.
- **Estruturas de Dados:** Vetores, matrizes, `List`, `Set`, `Map` e implementação de `hashCode` e `equals`.
- **Generics:** Classes genéricas, *wildcards*, covariância, contravariância e princípio GET/PUT.
- **Interfaces & Comparação:** Desacoplamento, resolução do problema do diamante, `Comparable` e `Comparator`.
- **Programação Funcional:** Expressões lambda, interfaces funcionais (`Predicate`, `Consumer`, `Function`, `Supplier`)
  e `Stream` API.
- **I/O:** Leitura e escrita de arquivos de texto.
